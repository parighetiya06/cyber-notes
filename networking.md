# Networking Basics

## Topics to Learn
- What is a network  
- Types of networks (LAN, WAN, MAN)  
- IP address  
- MAC address  
- OSI model  
- TCP/IP model  
- Ports and protocols  
- DNS  
- DHCP  

## Why am I learning this
Networking is the foundation of cybersecurity.  
If I understand networking, I can understand hacking, defense, and cloud security.
