# Linux Basics for Cybersecurity

## What is Linux
Linux is an open-source operating system widely used in servers, cloud systems, and cybersecurity tools.

## Why Linux is Important in Cybersecurity
- Most servers run on Linux
- Many cybersecurity tools work best on Linux
- Ethical hackers often use Linux-based systems
- Cloud platforms use Linux environments

## Topics I Will Learn
- Linux distributions (Ubuntu, Kali Linux, etc.)
- Linux file system
- Basic terminal commands
- Users and groups
- File permissions
- Processes
- Package managers

## Basic Linux Commands
- `ls` – list files
- `cd` – change directory
- `pwd` – show current folder
- `mkdir` – create a folder
- `rm` – remove a file
- `cp` – copy files
- `mv` – move or rename files

## Purpose
Learning Linux helps me understand systems, security tools, and cloud environments used in cybersecurity.
