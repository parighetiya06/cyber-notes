# Python Basics for Cybersecurity

## What is Python
Python is a simple and powerful programming language used for automation, scripting, and building tools.

## Why Python is Important in Cybersecurity
- Automates repetitive tasks
- Used in security tools
- Helps in scripting and hacking tasks
- Useful in cloud and AI security

## Topics I Will Learn
- Variables
- Data types
- Conditions (if-else)
- Loops (for, while)
- Functions
- File handling
- Basic scripts
- Libraries

## Example Uses in Cybersecurity
- Password strength checker
- Log file analyzer
- Port scanner
- Automation scripts

## Purpose
Learning Python will help me automate tasks and build tools in cybersecurity.
