# Cybersecurity Basics

## What is Cybersecurity
Cybersecurity is the practice of protecting computers, networks, systems, and data from cyber attacks.

## Why Cybersecurity is Important
- Protects personal data
- Protects company systems
- Prevents financial loss
- Protects national security
- Secures cloud and internet services

## Common Cyber Threats
- Malware
- Phishing
- Ransomware
- Social engineering
- Password attacks
- Denial of Service (DoS)

## CIA Triad (Core Security Principles)

### Confidentiality
Only authorized people should access sensitive information.

### Integrity
Data should not be changed or modified without permission.

### Availability
Systems and data should be available when needed.

## Basic Security Practices
- Use strong passwords
- Enable multi-factor authentication
- Keep software updated
- Be careful with suspicious links and emails

## Purpose
Understanding cybersecurity fundamentals helps build the foundation for advanced topics like ethical hacking, cloud security, and security engineering.
